## 🎮 Game Modes

| Mode | What's it about? |
|:--|:--|
| 🌍 **Syphi SMP** | A community-driven survival world with loot protection, proximity voice chat and full rollback support. |
| ⚔️ **SkyWarsFFA** | Jump in, fight, repeat. No waiting, big maps, personal stats and profiles. |
| 🗡️ **Duels** | Ranked 2v2 fights where only your true SkyWars skill counts. |
| ✨ **More to come** | New minigames and seasonal events are always in development. |

## ✨ Why Sypherox.dev?

- 🔗 **Discord linking** that syncs your in-game rank automatically
- 🌈 **Rank gradients** in chat, GUIs and player profiles
- 🗺️ **200+ SkyWars maps** to explore
- 🔊 **Custom shield break sounds** powered by our own Paper fork (coming soon)
- ⚡ **Self-hosted and self-built.** Every plugin is written in-house.
